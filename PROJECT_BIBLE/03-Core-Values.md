# Core Values

> **Our values define what we will protect, even when it would be easier not to.**

The following values guide every aspect of Project Resonance.

They provide a consistent foundation for product, design, and engineering decisions.

---

# Music First

Music is the reason Project Resonance exists.

Every feature should help musicians spend more time creating and less time managing technology.

---

# Simplicity

Simple experiences are rarely accidental.

We value thoughtful design that removes unnecessary complexity while preserving capability.

---

# Creativity

Creativity should never be interrupted by software.

Project Resonance exists to support inspiration, not compete for attention.

---

# Trust

Musicians should be able to rely on Project Resonance.

The application should behave predictably, preserve important work, and respect the user's creative process.

---

# Craftsmanship

Every screen, interaction, document, and line of code should reflect professional care.

Quality is not an optional feature.

It is inseparable from the product.

---

# Curiosity

Good ideas can come from anywhere.

We remain open to experimentation while evaluating every idea through the Resonance Test.

---

# Stewardship

We build Project Resonance with the future in mind.

Every decision should leave the product easier to understand, maintain, and improve.

---

# Decisions

- Core Values established.
- Craftsmanship adopted as a defining project value.
- Stewardship adopted as a long-term engineering principle.

---
